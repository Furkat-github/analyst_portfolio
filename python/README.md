## 🔎 Этапы анализа

Анализ данных был проведён в несколько последовательных этапов.

### 1️⃣ Первичный анализ данных

На первом этапе была выполнена загрузка и базовая проверка данных:

- анализ структуры таблиц
- проверка типов данных
- поиск пропущенных значений
- получение базовой статистики по транзакциям

Использовались следующие методы pandas:

```
df.info()
df.describe()
df.isna().sum()
```

Этот этап позволил убедиться в корректности данных перед проведением дальнейшего анализа.

### 📈 Ключевые продуктовые метрики
Daily Active Users (DAU)

В рамках анализа была рассчитана метрика DAU — количество уникальных пользователей, совершивших транзакции за день.

Метрика рассчитывалась следующим образом:

```
dau = df_transactions.groupby(df_transactions['date'].dt.date)['user_id'].nunique()
```

Данная метрика позволяет:

отслеживать ежедневную активность пользователей

анализировать динамику использования сервиса

выявлять изменения в поведении клиентов

## 📊 DAU динамика
![DAU](https://github.com/Furkat-github/analyst_portfolio/blob/main/python/images/Daily%20Active%20Users.png))

Monthly Active Users (MAU)

Также была рассчитана метрика MAU — количество уникальных пользователей, совершивших транзакции за месяц.

```
mau = df_transactions.groupby(df_transactions['date'].dt.to_period('M'))['user_id'].nunique()
```

MAU используется для:

оценки роста продукта

анализа уровня вовлечённости пользователей

сравнения активности пользователей между месяцами

### 💳 Анализ транзакций

Был проведён анализ типов транзакций пользователей.

Для каждого типа операций были рассчитаны:

количество транзакций

средний размер операции

общий оборот

Пример расчёта:

```
df_transactions.groupby('transaction_type')['amount'].mean()
```

Этот анализ позволяет понять:

какие операции наиболее популярны среди пользователей

какие операции формируют основной финансовый оборот.

### 💰 Анализ комиссий

Дополнительно был проведён анализ комиссий, которые сервис получает с транзакций.

Были рассчитаны:

общая сумма комиссий

комиссии по различным маршрутам переводов

```
df_transactions.groupby('route_type')['fee_amount'].sum()
```

Этот анализ помогает определить:

какие типы операций приносят наибольший доход сервису

какие каналы переводов являются наиболее прибыльными.

### 🔄 Анализ маршрутов переводов

В данных присутствуют различные маршруты переводов, включая:

переводы через Salom

прямые переводы между банками

Для оценки популярности продукта была рассчитана доля переводов через Salom.

salom_share = salom_count / all_tx * 100

Данный показатель позволяет оценить:

уровень использования продукта Salom

популярность различных способов перевода средств.

### 🏦 Анализ банков

Используя данные о банковских картах пользователей, был проведён анализ банков, которыми пользуются клиенты.

```
df_cards.groupby('bank_name')['user_id'].nunique()
```

Анализ позволил определить:

### 👤 Анализ активности пользователей

Также был проведён анализ пользователей с наибольшим объёмом транзакций.

## 📌 Основные выводы

По результатам проведённого анализа были выявлены следующие закономерности:

### 1️⃣ Активность пользователей

Метрики DAU и MAU позволяют отслеживать уровень активности пользователей и анализировать динамику использования сервиса.

### 2️⃣ Основные типы операций

Большая часть транзакций приходится на ограниченное количество типов операций, что является типичным для финтех-сервисов.

### 3️⃣ Использование различных маршрутов переводов

Анализ показал распределение транзакций между различными каналами переводов, включая Salom и прямые переводы между банками.

Это позволяет оценить популярность различных функций продукта.

### 4️⃣ Доход от комиссий

Комиссии распределяются неравномерно между различными типами операций.

Некоторые маршруты переводов формируют большую часть комиссионного дохода сервиса.

### 5️⃣ Концентрация транзакционного оборота

Анализ показал, что значительная часть общего оборота может приходиться на относительно небольшую группу пользователей.

Это типичная ситуация для финансовых сервисов.
