# [🗄️ SQL](https://github.com/Furkat-github/analyst_portfolio/blob/main/sql/bank_transactions.sql)): Анализ банковских транзакций

## 📌 Описание проекта

В этом проекте выполнен анализ банковских транзакций с использованием SQL.

Цель проекта — продемонстрировать навыки работы с базами данных, написания аналитических запросов и подготовки данных для дальнейшей аналитики.

Анализ включает:

- агрегацию транзакций
- сегментацию клиентов
- выявление аномалий
- анализ активности пользователей

Проект имитирует реальные задачи аналитика в финансовой компании.

# [🛒 Retail](https://github.com/Furkat-github/analyst_portfolio/blob/main/sql/retail_sales_analysis.sql): Анализ продаж в PostgreSQL

## 📌 Описание  
Проект посвящён анализу розничных продаж на основе данных из CSV, загруженных в базу данных PostgreSQL.  
Выполнен с использованием чистого SQL: расчёт выручки, возвратов, определение топовых товаров и ключевых показателей.

---
